# T-117 落地页完整版设计

## 目标

在不改变 MiraPrep 现有黑白灰与橙色品牌基调的前提下，补齐信任数据、Bento 功能展示、脱敏报告样例、FAQ 和滚动进入动画，让访客按“理解价值 → 建立信任 → 看见能力 → 看见结果 → 消除疑虑 → 开始使用”的顺序完成阅读。

验收目标包括：完整覆盖 T-117 模块、FAQ 键盘可达、已登录导航显示“进入工作台”、减弱动态效果正确降级，以及生产构建下 Lighthouse LCP 小于 2 秒。

## 页面叙事顺序

页面自上而下排列为：

1. 导航与 Hero
2. 题库方向条
3. 信任数据条
4. Bento 功能区
5. 报告样例
6. 四步流程
7. FAQ
8. CTA
9. Footer

该顺序先用营销数据建立信任，再通过功能与报告样例证明产品能力，最后用 FAQ 消除注册前疑虑。

## 组件边界

`src/app/page.tsx` 保持为服务端组件，负责静态文案、语义化区块和页面编排。需要浏览器状态或动画的模块拆为客户端组件：

- `StatBar.tsx`：渲染三项营销统计，在首次进入视口后滚动到目标数字。
- `RevealOnScroll.tsx`：封装统一的 Framer Motion 视口进入动画和 reduced-motion 降级。
- `ReportShowcase.tsx`：渲染脱敏报告浏览器窗口、综合评级、五维雷达图、逐题摘要和改进建议。
- `FaqAccordion.tsx`：使用已安装的 Base UI Accordion 提供手风琴状态、ARIA 语义和键盘行为。

Bento 功能区的数据与静态结构保留在 `page.tsx`。它由五张不等宽卡片组成，每张卡片包含一个轻量产品示意，而不只是装饰图标。

## 视觉与内容

### 信任数据条

采用现有营销数字口径，展示 `12,800+` 位候选人、`8` 类岗位方向和 `4` 步完成训练。数字使用 Space Grotesk、等宽数字和橙色强调，三项之间用轻分隔线组织。

### Bento 功能区

桌面端使用十二列 CSS Grid，重点能力占 7 或 8 列，辅助能力占剩余列；移动端退化为单列。五张卡片分别表达：

1. 基于回答继续追问，展示问题链路。
2. 围绕简历定制，展示技能与项目标签。
3. 语音或文字作答，展示声纹与实时转写。
4. 五维能力评估，展示微型评分条。
5. 可执行改进建议，展示一条“问题—建议”摘要。

卡片 hover 仅使用 `transform`、边框颜色和阴影，动画时长不超过 400ms。

### 报告样例

报告样例使用浏览器窗口外框和脱敏示例内容，突出综合评级 A、五维能力雷达图、逐题评价与下一步建议。桌面端采用左右分栏和少量悬浮层次，移动端改为单列。Recharts 图表位于首屏以下并延迟加载；即使图表尚未加载或不可用，文字分数仍完整可读。

### FAQ

FAQ 默认全部收起，同一时刻只展开一项。问题覆盖：是否需要真实面试官、如何定制问题、是否支持语音、报告包含什么、简历与录音如何处理、首次使用需要多久。触发器提供 Chevron 旋转、可见焦点环和完整按钮语义。

## 动效与无障碍

- 区块进入使用 300 至 400 毫秒淡入与最多 16px 上移，子项可轻量错峰。
- 统计数字只在首次进入视口时播放一次。
- reduced-motion 下取消位移、错峰和数字滚动，内容直接显示最终状态。
- 动画只改变 `transform` 与 `opacity`，避免布局抖动。
- FAQ 支持 Tab、Enter、Space 和方向键导航，并保持清晰焦点样式。
- 装饰性图形不进入可访问性树；有信息含义的分数同时提供文字。
- 页面标题层级、`section`、`nav`、`footer` 与 FAQ 按钮保持语义化。

## 登录态

`LandingNav` 继续使用现有 `useAuthToken`。存在 token 时登录入口显示“进入工作台”并链接 `/dashboard`；否则显示“登录”并链接 `/auth`。不新增后端请求。

## 性能策略

- Hero 和核心文案保持服务端输出，不增加首屏大图。
- 报告图表在首屏以下延迟加载，避免进入 LCP 关键路径。
- 不为装饰效果引入新的大型资源；优先使用现有 Framer Motion、Recharts、Base UI 和 CSS。
- 固定示意区域尺寸，避免异步图表造成布局偏移。
- 动画避免影响布局或主线程长任务。
- 使用生产构建运行 Lighthouse 移动端审计，以 LCP 小于 2 秒为硬门槛。

## 测试与验收

实现遵循测试驱动开发：每个新行为先写测试并观察其因缺少功能而失败，再实现最小代码使其通过。

自动化测试覆盖：

- `StatBar` 显示三项最终数字，reduced-motion 下不等待动画。
- `FaqAccordion` 默认收起、点击与键盘可展开，并保持单项展开。
- `ReportShowcase` 始终提供可读的评级、维度分数和脱敏标识。
- `RevealOnScroll` 在 reduced-motion 下不产生位移。
- 落地页包含全部规定区块和正确锚点。
- `LandingNav` 在有无 token 时呈现正确链接与文案。

完成前依次运行 ESLint、TypeScript、Vitest、生产构建和 `git diff --check`。随后启动真实 Next.js 页面，在桌面和移动视口检查完整页面、FAQ 键盘操作、登录态、reduced-motion 与浏览器控制台，并保存分段截图。最终在生产构建上运行 Lighthouse 移动端审计；若 LCP 未达到 2 秒，依据报告继续优化并重测。
