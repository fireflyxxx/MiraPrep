# T-121 · 「重练此题」迷你练习

| 轨道 | 里程碑 | 预估 | 依赖 | 阻塞 |
|---|---|---|---|---|
| Full-stack | M3 | 1.5d | T-040, T-101, T-105, T-108 | — |

## 背景
报告页每题有「重练此题」入口（PRD §3.8，可先占位）。本任务实现单题迷你练习模式。

## 目标
从报告某题进入单题练习：重新回答该题一次 → 立即结束练习并批改 → 给出与上次答案的对比反馈。

## 范围
- **做**：后端创建「单题练习」轻量会话（复用面试基础设施但限定单题、单次作答）、前端报告页内的专注答题弹窗（复用正式面试的实时通信与文字/语音能力，但采用独立界面）、练习结果与原答案对比。
- **不做**：完整多题面试（已有）；练习历史沉淀可最小化。

## 技术规格
- 单题练习只接受一次回答：展示原题 → 用户提交回答 → 自动结束会话并进入批改；不运行完整阶段状态机、不追问、不生成下一题。
- 复用正式面试已有的文字流、录音、ASR、TTS、消息持久化与断线恢复能力，不复制实时通信逻辑；会话类型标记为「单题练习」。
- 即时评分复用 T-105 的**单题批改 chain**（`QuestionReview` 结构化输出），不重写评分逻辑。
- 后端：`POST /interviews/{sessionId}/questions/{questionId}/retry` → 建练习子会话，返回 practice sessionId；结束后给该题的即时评分与对比。
- 前端：从报告逐题卡「重练此题」打开专用的“重新回答这道题”弹窗。作答阶段只显示题目、本次回答、语音/文字切换和一次提交操作，不嵌入或缩放正式面试页面；共享其 SSE/WebSocket、消息恢复、录音、ASR 与 TTS 运行能力。结束后原地展示「本次 vs 上次」对比。

## 涉及文件
- 后端 `interview/PracticeController.java` + service（复用面试基础设施）
- AI 侧：为 `interview_agent` 增加单次作答的 practice 模式，并复用 `grading` 的单题 chain；禁止复制粘贴实时通信或评分逻辑
- 前端：报告卡按钮接入 + `PracticeDialog` + 独立 `PracticeAnswerCard`，通过无头运行层复用正式面试的实时与语音组件

## 验收标准
1. 从报告某题打开独立设计的专注答题弹窗；弹窗不出现正式面试页头、总计时、题目进度、面试官舞台、回看或结束面试控件。
2. 作答阶段隐藏原答案、原得分和改进建议，完成一次文字或语音作答后自动结束，不出现追问或下一题，并给出该题即时反馈。
3. 展示本次与上次回答/得分对比。
4. 练习不污染原面试记录与统计（或明确单独计）。
5. `lint`/`typecheck`/`test`/`build` 通过。

## 验证方式
PR 贴：从报告打开练习弹窗 → 文字/语音作答一次 → 自动批改 → 对比的全流程截图。
